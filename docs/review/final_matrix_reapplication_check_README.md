# Empirical Rules Final Recode (2026-08-30)

This is the completed independent recoding package produced from `DELIVERY_TO_OY_EMPIRICAL_RULES_20260830` only. It contains all 300 sampled field tasks (60 studies x 5 fields) and a separate 60-row binary descriptor for explicit use of a public benchmark, CVE/known-CVE corpus, or public dataset.

The recoded external-traceability labels are exactly `no external trace reported`, `author-reported external clue`, and `item-aligned external record`. Benchmark or public-material use is never used as an external-traceability label. Lifecycle and cross-stage positives require concrete, source-located workflow evidence; `not observable in supplied material`, `unresolved`, and `material mismatch` remain whole-cell states where applicable.

Evidence locators identify an actual PDF page plus extracted-text line or a TXT line. Excerpts are contiguous text from the corresponding supplied material. The package excludes the scoring key, final matrix, historical coder files, and earlier review outputs.
