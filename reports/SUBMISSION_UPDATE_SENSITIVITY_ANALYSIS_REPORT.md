# Submission Update Rerun Sensitivity Analysis

This report compares author-confirmed final labels with the rerun independent second-coder labels for the 41 full-text records in the July 15 submission-update round. The rerun template instructed the coder to use the revised boundary notes and not to inspect author audit files, adjudication files, or previous coder2 results before coding.

## Headline fields

- Reproducible validation: author-final 17, rerun second-coder 15, absolute difference 2.
- Externally traceable material: author-final 4, rerun second-coder 5, absolute difference 1.
- Feedback interpretation / loop adjustment: author-final 36, rerun second-coder 35, absolute difference 1.
- Validation organization / evidence packaging: author-final 39, rerun second-coder 38, absolute difference 1.
- Failure reuse / strategy update: author-final 11, rerun second-coder 8, absolute difference 3.
- Governance / human gates / disclosure control: author-final 5, rerun second-coder 8, absolute difference 3.

## Maximum label-count movement by field

- strongest_evidence_output: maximum absolute label-count difference 2 (reproducible validation).
